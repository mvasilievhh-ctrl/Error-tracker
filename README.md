# Журнал ошибок выписки — бот + сайт

Живой сайт-трекер, который сам ловит сообщения от вашего Telegram-бота в группе,
парсит их и показывает в таблице. Обновляется каждые 5 секунд без перезагрузки страницы.

## Что внутри

- `app.py` — сервер (Flask): слушает Telegram, парсит сообщения, хранит их в базе,
  отдаёт веб-страницу и API.
- `templates/index.html` — сама страница со таблицей.
- `requirements.txt`, `Procfile` — для деплоя.

## Шаг 1. Получите токен бота

Если бот уже существует и вы его администрируете:
1. Откройте в Telegram чат с **@BotFather**
2. Отправьте `/mybots`, выберите вашего бота
3. **Bot Settings → API Token** — скопируйте токен (выглядит как `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxx`)

**Важно:** чтобы бот видел все сообщения в группе (а не только команды, начинающиеся с `/`),
отключите privacy mode:
- В BotFather: `/mybots` → выберите бота → **Bot Settings → Group Privacy → Turn off**

## Шаг 2. (Опционально) узнайте ID группы

Если бот состоит в нескольких группах, а вам нужны сообщения только из одной — узнайте её `chat_id`:
1. Добавьте бота в группу (если ещё не добавлен)
2. Напишите любое сообщение в группу
3. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. В ответе найдите `"chat":{"id": -100123456789, ...}` — это и есть chat_id (отрицательное число для групп)

Если это единственная группа, где работает бот — можно пропустить, тогда бот будет
обрабатывать сообщения из любых чатов, куда он добавлен.

## Шаг 3. Разверните на Render.com (бесплатно)

1. Зарегистрируйтесь на [render.com](https://render.com)
2. Загрузите эту папку в GitHub-репозиторий (или используйте "Deploy from folder" если доступно)
3. В Render: **New → Web Service** → подключите репозиторий
4. Настройки:
   - **Runtime:** Python 3
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn app:app --workers 1 --threads 4 --timeout 60`
5. В разделе **Environment** добавьте переменные:
   - `TELEGRAM_BOT_TOKEN` = ваш токен из Шага 1
   - `TELEGRAM_CHAT_ID` = ID группы из Шага 2 (необязательно)
6. Нажмите **Deploy**

После деплоя Render выдаст вам ссылку вида `https://your-app.onrender.com` — это и есть
ваш живой сайт-трекер.

**Важно про бесплатный тариф Render:** бесплатные сервисы "засыпают" после 15 минут
без запросов и просыпаются ~30-60 секунд при следующем визите. Если нужно, чтобы бот
ловил сообщения непрерывно 24/7 без задержек — потребуется платный тариф (от ~$7/мес)
или Railway с похожими условиями.

## Локальный запуск (для проверки перед деплоем)

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш_токен"
python app.py
```

Откройте `http://localhost:5000`

## Формат сообщений, которые бот распознаёт

```
Ошибка выписки
Номер заказа B2C: 7385
Номер заказа GTS: 88602
Провайдер: Тестовый
Сообщение ошибки: текст ошибки...
```

Если к сообщению приложен текстовый файл (.txt) — он тоже сохранится и будет доступен
для скачивания прямо из таблицы.

## Если нужно изменить формат парсинга

Правки вносятся в файл `app.py`, функция `parse_message()` — там регулярные выражения,
которые ищут строки вида `Название поля: значение`.
