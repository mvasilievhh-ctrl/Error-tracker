# ИИ-агент погоды: Москва и соседние области → Excel

Агент каждые 5 минут опрашивает погоду в 16 городах и складывает всё в Excel-таблицу.
Если подключить ключ Anthropic, Claude раз в час пишет короткую сводку: общая картина,
где теплее и где холоднее, что изменилось за час, есть ли опасные явления (сильный ветер,
гроза, гололёд и т. п.).

**Какие города опрашиваются:**
- Москва;
- Московская область: Химки, Мытищи, Балашиха, Подольск, Сергиев Посад, Коломна, Серпухов, Можайск;
- соседние области (по областному центру): Тверь, Ярославль, Владимир, Рязань, Тула, Калуга, Смоленск.

Погоду агент берёт из [Open-Meteo](https://open-meteo.com): это бесплатно и без регистрации.

## Что внутри

- `agent.py` — сам агент: опрос погоды, база, Excel, ИИ-сводки.
- `cities.json` — список городов (можно править).
- `requirements.txt` — зависимости.
- `data/` — появляется после первого запуска: Excel-файлы, база `weather.db`, лог `agent.log`.

## Установка

Нужен Python 3.10 или новее.

```bash
cd weather_agent
pip install -r requirements.txt
```

## Запуск

```bash
python agent.py
```

Агент работает, пока открыто окно. Остановить его можно сочетанием `Ctrl+C`.

Другие варианты:

```bash
python agent.py --once          # один опрос и выход
python agent.py --interval 10   # опрашивать раз в 10 минут
python agent.py --no-ai         # без ИИ-сводок, только данные
```

## Включить ИИ-сводки (Claude)

1. Получите ключ на [console.anthropic.com](https://console.anthropic.com) (раздел **API Keys**).
2. Перед запуском задайте переменную окружения.

   Windows (PowerShell):
   ```powershell
   $env:ANTHROPIC_API_KEY="sk-ant-..."
   python agent.py
   ```
   macOS / Linux:
   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."
   python agent.py
   ```

Без ключа агент тоже работает: собирает данные, но сводок не пишет.

**Сколько это стоит.** По умолчанию работает модель `claude-opus-5-5` с низким уровнем
рассуждений (effort `low`). Одна сводка обходится примерно в 2–3 цента, при сводке раз в час это
около $0.5–0.7 в день. Это оценка, точный расход видно в консоли Anthropic. Если сводки нужны реже,
поднимите `AI_INTERVAL_MINUTES`. Если запрос отклонят фильтры безопасности модели, он автоматически
повторится на рекомендованной резервной модели (параметр `fallbacks: "default"`).

## Что лежит в Excel

На каждый месяц создаётся отдельный файл: `data/weather_2026-10.xlsx`, `data/weather_2026-11.xlsx` и т. д.
В каждом файле три листа:

| Лист | Что на нём |
|---|---|
| **Сейчас** | последний опрос: по одной строке на город |
| **Журнал** | все опросы за месяц: время, город, регион, температура, «ощущается как», влажность, давление (мм рт. ст.), ветер и порывы (м/с), направление ветра, облачность, осадки, описание погоды |
| **Сводки ИИ** | сводки Claude, сверху самые свежие |

На всех листах закреплена шапка и включён автофильтр, так что можно фильтровать по городу и строить графики.

Полная история за всё время хранится в базе `data/weather.db`, а Excel-файл пересобирается из неё
на каждом цикле. Поэтому:
- если файл открыт в Excel, агент не сможет его перезаписать. Данные при этом не теряются:
  файл обновится на следующем цикле после того, как вы его закроете. Чтобы увидеть свежие данные,
  переоткройте файл;
- правки, которые вы внесли прямо в файл агента, будут перезаписаны. Если хотите что-то
  дорабатывать вручную, сохраните копию под другим именем.

Отдельный файл на месяц нужен, чтобы таблица открывалась быстро: за месяц набегает около 140 тысяч строк.

## Важно про частоту данных

Open-Meteo обновляет текущую погоду раз в 15 минут. Агент спрашивает каждые 5 минут, поэтому
2 из 3 опросов подряд обычно показывают те же цифры. Чтобы понять, когда данные реально
обновились, смотрите колонку «Время данных». ИИ-сводка по одним и тем же данным повторно не пишется.

Бесплатный лимит Open-Meteo — 10 000 запросов в сутки, причём каждый город считается отдельным
запросом. При 16 городах и опросе раз в 5 минут выходит около 4 600 в сутки. Если сильно увеличите
список городов или частоту опросов, можно упереться в лимит.

## Настройки

Всё задаётся переменными окружения, все они необязательные:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ Anthropic для ИИ-сводок |
| `CHECK_INTERVAL_MINUTES` | `5` | как часто опрашивать погоду (то же, что `--interval`) |
| `AI_INTERVAL_MINUTES` | `60` | ИИ-сводка не чаще, чем раз в N минут (`0` — при каждом обновлении данных) |
| `AI_MODEL` | `claude-opus-5-5` | какая модель Claude пишет сводки |
| `WEATHER_DATA_DIR` | `weather_agent/data` | куда класть Excel, базу и лог |
| `CITIES_FILE` | `weather_agent/cities.json` | файл со списком городов |

## Как добавить или убрать город

Откройте `cities.json` и добавьте строку по образцу:

```json
{"city": "Звенигород", "region": "Московская область", "lat": 55.7297, "lon": 36.8550}
```

Координаты (`lat` — широта, `lon` — долгота) можно взять, например, в Яндекс Картах: кликните по
точке, и координаты появятся в карточке места. Первый город в списке агент показывает в коротком
сообщении в логе.

## Как запускать в фоне

**Windows, через Планировщик заданий.** Создайте задачу, которая при входе в систему запускает
`python C:\путь\к\weather_agent\agent.py`, и в настройках снимите галочку «Останавливать задачу,
если она выполняется дольше…». Ключ Anthropic в этом случае задайте как постоянную переменную
окружения пользователя: «Параметры → Система → О системе → Дополнительные параметры системы →
Переменные среды».

**Linux / macOS, через cron.** Вместо бесконечного цикла можно запускать один опрос каждые 5 минут:

```
*/5 * * * * cd /путь/к/weather_agent && ANTHROPIC_API_KEY=sk-ant-... /usr/bin/python3 agent.py --once
```

**Сервер.** На бесплатном тарифе Render (через который развёрнут трекер ошибок из этого репозитория)
файлы удаляются при каждом перезапуске, поэтому Excel там не сохранится. Агента лучше запускать
на своём компьютере или на сервере с постоянным диском.
